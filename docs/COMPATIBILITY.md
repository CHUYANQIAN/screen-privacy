## 恢复与配置行为

三个默认组合为 Ctrl+Alt+F8（主屏）、Ctrl+Alt+F9（全部副屏）、Ctrl+Alt+F10（恢复全部），均可配置和持久化。当前恢复键不可用时，任何新的遮蔽都被禁止；主副屏动作按各自实际注册结果决定是否可开始。

旧配置仅在缺少 `RestoreHotkey` 字段时补默认值，保留其他键位、样式与密码记录。显式空值、非法组合或重复组合会报错，不无声重置。新设置登记和原子保存均成功后才提交；失败尝试恢复旧登记，并报告实际回滚结果。

### 面板、全部遮蔽与退出

部分屏幕遮蔽时，面板可以保留在或移到未遮蔽的屏幕；全部屏幕遮蔽时隐藏，进程和恢复键仍然驻留。未开启最小化选项时，解除最后一块遮罩后面板自动返回遮蔽前的位置；若显示布局已经改变，则调整到当前可显示区域。开启该选项时，面板也会最小化，仍可从任务栏或托盘唤回。

“遮蔽全部屏幕”只为当前未遮蔽的屏幕增加遮罩，不把已遮蔽的屏幕反向恢复。它与主屏、副屏快捷键原有的切换语义不同。右上角关闭只收起到托盘，“退出软件”才结束程序；正常恢复不会顺带退出程序。

### 恢复后最小化

`MinimizeOnRestore` 默认关闭，旧配置缺少字段时也保持关闭。在“设置 → 常规”勾选“恢复遮蔽后最小化所有应用窗口”后，只有成功授权且本次恢复将解除最后一块遮罩时，才请求最小化其他普通应用窗口。请求在遮罩仍存在时发出，随后恢复显示并将本软件面板也最小化。程序继续运行，恢复后的目标画面是桌面，可从任务栏或托盘唤回本面板。仅解除部分遮罩、错误密码、取消或无遮罩的恢复请求都不触发。

普通应用枚举会排除本软件进程中的遮罩等内部窗口、桌面/任务栏、工具或特殊窗口、已最小化窗口等不适合处理的对象；控制面板在恢复显示时单独最小化。最小化请求不等于所有窗口已经完成；程序短时等待并确认结果，失败或超时仍继续恢复显示，记录未能确认的结果，不会无限等待而困在遮罩中。权限受限、无标准最小化能力或特殊窗口可能无法最小化。

密码最多三个，任一有效。新条目使用随机盐与 PBKDF2-SHA256 600,000 次派生，不保存明文；此机制不等同系统身份认证。每个新进程在首次成功遮蔽之前允许免旧密码管理；首次成功后关闭该窗口，恢复和托盘收起不会重开。结束进程再启动会重新开放，结束进程本身也会解除遮罩。

这些为当前实现；自动化检查覆盖范围与作者使用确认分别见[验证记录](VALIDATION.md)。

## 捕获、显示与电源边界

工具让实体屏幕显示遮罩，并尝试让兼容捕获路径排除遮罩窗口，保留底层桌面图像。实现使用 `WDA_EXCLUDEFROMCAPTURE`。该标志自 Windows 10 2004 起支持，早期行为不同；这只是 API 技术起点，不能据此认定本软件在所有后续 Windows 上兼容。它依赖 DWM，微软也未将此机制描述为全面内容保护保证。[Microsoft API 说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)

全局热键通过实际 `RegisterHotKey` 结果确认；键位可能被其他应用占用，F12 为保留键，不接受配置。[Microsoft 热键说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)

遮罩不拦截正常桌面输入，不物理关闭背光，也不创建隔离会话。进程退出或异常后遮罩不继续存在；系统安全桌面、某些全屏或置顶窗口、其他捕获接口可能有不同表现。

显示布局变化时，当前策略是尝试先补盖所有当前屏幕，再移除旧罩；不承诺切换瞬间零露出。密码窗口可能取得键盘焦点，软件没有自动暂停或恢复 Codex 任务的集成。

遮蔽期间临时请求系统和显示保持活动，全部恢复后释放，不修改电源计划；这不能保证阻止主动睡眠、合盖、屏保或系统策略。主屏模拟更新只是画面样式，不执行系统更新或按进度重启、解锁。

**减少现场旁观，桌面内容仍对 Codex 可见。** 截图预览、屏幕共享、录屏和远程访问仍可能展示底层内容；请按相应工具管理访问范围。

## 构建与复现

当前源文件的构建入口已在本机成功执行：

```powershell
.\tools\build.ps1 -OutputDirectory .\build
```

从仓库根目录运行，脚本寻找 Windows .NET Framework 的 C# 编译器，将产物写入独立目录。新编译件应另算 EXE SHA-256 并重跑适用检查，不沿用既有二进制身份。

逻辑自检可在构建后运行 `build/ScreenPrivacy.exe --self-test --report logic-results.json`，不会显示遮罩。原生热键探测会短时占用所测键位，应在没有本软件实例占用同组键的测试环境进行；不要用该探测替代真实键盘恢复验收。
