# 屏幕遮蔽 · ScreenPrivacy

## 屏幕遮蔽，调试继续

面向 Codex 桌面调试的 Windows 临时防旁观工具。**把实体显示器上的项目画面遮住，同时保留活动桌面，让兼容的截图、点击与输入链路继续工作。**

**减少现场旁观，桌面内容仍对 Codex 可见。**

当前版本：**v0.3.1**。本次修正遮蔽与恢复时的面板行为，并加入可选的恢复后最小化功能；检查结果与环境范围见[验证记录](docs/VALIDATION.md)和[兼容性说明](docs/COMPATIBILITY.md)。

### 当前实现

- **按主副屏分组控制，也可一键全部遮蔽。** 系统主屏与其余全部副屏分别控制；“遮蔽全部屏幕”只补上当前未遮蔽的屏幕，不会反向恢复已遮蔽的屏幕。副屏作为一组，暂不支持逐台选择。
- **为活动桌面保留操作通道。** 遮罩采用不激活、点击穿透和兼容捕获排除机制，不创建另一桌面会话。截图与输入兼容范围以实际使用环境为准。
- **面板位置随遮蔽范围调整。** 部分遮蔽时，面板留在或移到未遮蔽的屏幕；全部遮蔽时隐藏，软件继续驻留。最后一块遮罩解除后，默认自动回到原位置；开启最小化选项后，本面板也会最小化。
- **用自己的组合键请求恢复。** 主屏、副屏与恢复全部三组全局快捷键均可修改、保存。全部遮蔽后的恢复入口是全局快捷键；可选密码验证提供额外确认。

适合较长的 AI 界面调试、同室或共享工作空间的临时防旁观，以及多显示器工作台的屏幕分工。软件独立运行，没有 Codex 连接状态检测或任务管理功能。

## 下载与开始使用

从 [v0.3.1 发布页](https://github.com/CHUYANQIAN/screen-privacy/releases/tag/v0.3.1) 下载 **ScreenPrivacy-v0.3.1-windows-anycpu.zip**，并按发布页的 SHA-256 校验文件。

便携包需要完整解压到可写目录，运行其中的 `app/ScreenPrivacy.exe`。程序需要 Windows 活动桌面及 **.NET Framework 4.8**；已检查与尚未验证的环境见 [兼容性说明](docs/COMPATIBILITY.md)。EXE 当前未进行代码签名。

1. 启动默认不遮蔽。先查看主面板的“恢复快捷键”，或在设置中修改。
2. 保存设置，确认“恢复快捷键已就绪”，记住实际生效的组合键。
3. 选择“遮蔽主屏”“遮蔽全部副屏”或“一键遮蔽全部屏幕”。部分遮蔽时，可在未遮蔽屏幕上的面板继续操作；全部遮蔽时面板隐藏，软件仍在运行。
4. 需要查看画面时，按已保存的恢复组合键。开启密码验证时，再输入任一有效密码并按 **Enter**。最后一块遮罩解除后，默认自动显示面板；勾选最小化选项后，包括本面板在内的应用窗口会最小化。

| 操作 | 默认快捷键 | 可自定义并保存 |
| --- | --- | --- |
| 切换主屏遮蔽 | Ctrl + Alt + F8 | 是 |
| 切换全部副屏遮蔽 | Ctrl + Alt + F9 | 是 |
| 恢复全部屏幕 | Ctrl + Alt + F10 | 是 |

恢复全部键只负责恢复，无遮罩时不会反向开启遮蔽。自定义后，以面板显示的组合为准，旧 F10 不会继续充当隐藏的恢复键。恢复键注册失败时，程序禁止开始新的遮蔽；主副屏键分别显示其实际注册状态。

### 恢复后最小化所有应用窗口

在 **设置 → 常规** 勾选“恢复遮蔽后最小化所有应用窗口”。默认关闭。

开启后，软件在成功授权并即将解除最后一块遮罩时，先请求其他普通应用窗口最小化，再恢复显示，本面板也会最小化，让屏幕回到桌面。程序继续运行，可从任务栏或托盘唤回。仅恢复部分屏幕、取消或验证失败时，不执行这一操作。窗口请求失败或短时等待超时后，仍会继续恢复显示并提示未能确认的结果，不会一直停留在遮罩中。

该选项针对可控制的普通应用窗口，不承诺所有系统、悬浮、受权限限制或特殊窗口都能最小化。右上角关闭只会收起到托盘；结束程序请使用“退出软件”。

### 恢复密码与样式

密码验证默认关闭，最多记住三个密码，任意一个正确即可恢复。未修改的密码继续沿用；关闭验证不会删除已保存条目，删除是单独操作。

启用后，恢复键显示密码窗口，输入后按 **Enter** 验证；错误、空输入、**Esc** 或取消会保持遮蔽。验证与新密码生成在后台计算，取消后的迟到结果由请求状态拒绝。

忘记密码时，可真正结束软件后重新启动，在本进程首次成功开启遮蔽前重设。结束进程会解除遮罩；关闭面板到托盘不算重启。这是便捷的恢复规则，不是不可绕过的安全锁。

主屏可选纯黑或模拟更新，副屏保持纯黑。模拟更新只改变画面，不执行 Windows 更新，不重启，也不会按进度自动解除遮蔽。

## 验证与兼容范围

本轮检查覆盖 **159 项逻辑断言、5 项真实 Win32 热键注册与回退阶段**、两个专门创建的窗口的原生最小化测试，以及控制器生命周期的 22 项检查。最小化测试只针对专用测试窗口，没有据此推断所有应用均兼容。各项结果、实屏回归范围及对应构建的 SHA-256 见[验证记录](docs/VALIDATION.md)。

其他 Windows 版本、x86/ARM64、混合 DPI、多副屏、热插拔和长时间资源表现尚未全面覆盖。详细环境与已知边界见[兼容性说明](docs/COMPATIBILITY.md)。

首次在新环境使用时，可先用无敏感内容的桌面确认实体画面、Codex 新截图、实际输入和键盘恢复。

## 隐私边界

本工具保留 Codex 对底层桌面的访问，不向 Codex 隐藏项目。截图、屏幕共享、远程访问和聊天中的截图预览仍可能显示底层内容。

软件遮罩不替代 Windows 锁屏，不锁定鼠标键盘，也不是物理关闭显示器。进程终止、软件异常、某些系统或置顶界面、显示布局变化都可能影响遮蔽。遮蔽期间避免盲点底下应用。

## 从源码构建

在 Windows PowerShell 中进入仓库根目录，运行：

```powershell
.\tools\build.ps1 -OutputDirectory .\build
```

脚本使用 Windows 的 .NET Framework C# 编译器，构建到独立 `build/`，生成主程序、历史兼容恢复入口及所需应用配置。当前目标为 **AnyCPU**；这不代表 x86、ARM64 或所有 Windows 版本均已实测。源码再次构建可能得到不同二进制哈希，应对新产物重新记录验证身份。
